# NumPy 2 – Advanced Array Operations

This Python project focuses on learning and implementing NumPy (Numerical Python), a powerful library used for scientific computing, data analysis, and numerical operations.

## Topics Covered
1. Creating NumPy Arrays
2. One-Dimensional and Two-Dimensional Arrays
3. Array Indexing and Slicing
4. Array Reshaping
5. Array Attributes
6. Arithmetic Operations
7. Matrix Operations
8. Broadcasting
9. Statistical Functions
10. Sorting and Searching
11. Copying and Viewing Arrays
12. Joining and Splitting Arrays

## Libraries Used
- Python
- NumPy

## Learning Objectives
- Understand array-based computing.
- Perform mathematical calculations efficiently.
- Work with multidimensional arrays.
- Develop a foundation for Data Science and Machine Learning.
